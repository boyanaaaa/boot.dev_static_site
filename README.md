# Boot.dev Static Site Project

This project is part of the Boot.dev curriculum. It focuses on building a simple static site generator in Python from scratch.

## 📌 Overview

The goal of this project is to learn how to:

- Build custom data structures in Python
- Work with classes and inheritance
- Parse and represent text as structured nodes
- Convert structured data into HTML
- Write and run unit tests
- Use Git for version control
